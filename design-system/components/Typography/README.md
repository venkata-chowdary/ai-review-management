Typography: the Manrope type scale with weights, figures and usage.

- **Font:** Manrope (`--font-manrope`) everywhere.
- **Weights:** 700 for headings and metric figures, 600 for buttons, tabs, navigation and labels, 500 for meta, 400 for reading text.
- **Styles:** `display`, `page-title`, `section`, `card-title`, `body`, `control`, `label`, `small`, `metric`.
- **Numbers:** turn on tabular figures (`font-feature-settings: "tnum" 1`) so numbers align in tables and KPI tiles.
- **Tracking:** −1.5% to −2% on `display`, `page-title` and `metric`; default elsewhere.
- **QR page inputs:** 16px text so phones don't zoom.
