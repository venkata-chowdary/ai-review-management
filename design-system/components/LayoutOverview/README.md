Overview home layout: a slim glass icon rail, a greeting with location and date filters, an action queue, KPI tiles with trends, and a recent-reviews table.

**Use it for** the landing page, so owners immediately see what needs doing.

**Structure**
- `rail-width` (76px) glass rail with labelled icons and an AI-usage ring (82%) at the bottom.
- Action queue of three cards:
  - **12 awaiting approval:** the lead card, glossy blue like the primary button, with a white "Review now" button.
  - **1 failed:** with Retry.
  - **88 AI replies left:** with a meter.
- Four KPI tiles with weekly bars.
- Recent-reviews table: fixed columns, statuses as badges, hover rows on `bg-row-hover`.
- Rating breakdown.

**Pairs well with** the Inbox split as the Reviews page.
